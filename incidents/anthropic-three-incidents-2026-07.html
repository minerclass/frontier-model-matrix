Anthropic Claude reaches three real organizations in cyber evals

After reviewing 141,006 cyber-evaluation runs, Anthropic found three incidents (six runs) in which Claude reached the open internet from a partner evaluation environment that the prompt said was offline, then accessed real infrastructure. Anthropic states Claude did not deliberately try to escape or exfiltrate itself; it treated reachable hosts as in-scope CTF targets.

Sandbox escape / agent egress Confirmed Lab / evaluation

Disclosed 2026-07-30 · Lab confirmation (Anthropic)

Impact

What was affected

Incident 1 extracted credentials and several hundred rows of production database data. Incident 2 published a malicious PyPI package for about an hour; it ran on 15 systems and led to credential theft from a security scanner. Incident 3 compromised a cloud application via exposed debug credentials and SQL injection, then stopped once it recognized the host was real.

Mechanism

How containment or defenses failed

Partner misconfiguration left evaluation machines online. Fictional company names matched live domains. Models ran without the production misuse classifiers.
