CursorBench 4.0

Cursor runs agents on ambiguous multi-file tasks taken from real Cursor sessions. This is the shared coding harness in the repository. Cost, tokens, and steps are Cursor's per-task averages.

https://cursor.com/cursorbench

How this harness compiles a score

  • Each row is one model at one effort setting.
  • The score is a percent. Higher is better.
  • Cursor names the effort. Composer 2.5 is listed without an effort.
  • A model absent from this file had no row on the board when it was read on 13 Oct 2026.

What this page does not claim

  • GPT-6 Astra, GPT-6 Sol, GPT-6.1 Sol, GPT-6 Luna, Muse Wonder, and Muse Wonder Full are absent.
  • These scores are not comparable, one for one, with Terminal-Bench or DeepSWE.
