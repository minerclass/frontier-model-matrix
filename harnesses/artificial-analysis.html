How this harness compiles a score

  • Intelligence Index v4.3 combines ten evaluations AA runs.
  • The article gives Spark 1.3, Wonder, and Wonder Full at max effort.
  • Coding Agents Index scores are for the named agent product: Muse Code for Muse models.
  • Cost per index task is AA's estimate for its own task mix. It is not a CursorBench task cost.

What this page does not claim

  • Wonder Full has no token price, so AA does not publish a cost per task for it.
  • AA's Terminal-Bench percent for Wonder Full is 57, which the article calls level with Gemini 4 Argon high on AA's run. That is not Anthropic's 66.4%.
