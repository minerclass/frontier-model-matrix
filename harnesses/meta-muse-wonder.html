Meta Muse Wonder table

Meta's 12 Oct 2026 developer table for Muse Wonder and Muse Wonder Full. Press coverage on 13 Oct calls the family Watermelon. Meta's own posts use the Wonder names.

https://dev.meta.ai/resources/blog/build-with-muse-wonder

How this harness compiles a score

  • Wonder and Wonder Full cells are Meta's reported results at max effort unless a row says otherwise.
  • SWE-Marathon for Wonder Full is xhigh.
  • Terminal-Bench uses Artificial Analysis as the result source, so those cells are AA's run as cited by Meta.
  • DeepSWE uses Datacurve for Wonder, Wonder Full, and Opus, OpenAI's number for Astra, and Anthropic's system card for Fable.
  • Competitor cells are whatever source Meta names. They are not a fresh common-harness run unless the model card says so.

What this page does not claim

  • Wonder Full has no per-token price and is limited to Muse Code Power and Maximum.
  • Wonder API price is $4 input and $20 output per million tokens, with a 1M context.
  • Neither Wonder model is on CursorBench.
  • AutomationBench-AA is not the Zapier AutomationBench used by OpenAI and Google.
