Moonshot AI Kimi K3.1 Pro model card

Moonshot AI's Kimi K3.1 Pro model card (23 Oct 2026, 2.8T total / 104B active MoE) comparing Kimi K3.1 Pro at max effort against Claude Fable 5.1, GPT-6 Astra, Claude Opus 5.5, DeepSeek V4.1 Flash 1017, and GLM 5.3.

Primary URL: https://huggingface.co/moonshotai/Kimi-K3.1-Pro ↗ · 11 benchmarks · 64 recorded cells

How this harness compiles a score

  • Kimi K3.1 Pro runs at max reasoning effort (`temperature = 1.0`, `top-p = 0.95`). Coding benchmarks use the Claude Code harness; OSWorld V2.1 uses Kimi Agent.
  • Moonshot's footnotes identify where competitor rows come from model blog posts, technical reports, Artificial Analysis, Vals AI, or Moonshot's own internal runs.
  • ProgramBench on Moonshot's card uses binary task scoring (>=95% counts as 1, otherwise 0) and is kept on its own benchmark id so it is not confused with Meta's continuous ProgramBench row.

Scope & boundaries

  • On Terminal-Bench-Science 0.1, Moonshot's footnote states that the 15.7 cell in the DeepSeek column is for the older DeepSeek V4.1 Flash from the official leaderboard (internal 1017 run was 9.3), so that cell is omitted for 1017 here.
  • API pricing is $2 input and $10 output per million tokens.
