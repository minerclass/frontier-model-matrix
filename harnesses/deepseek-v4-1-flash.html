DeepSeek V4.1 Flash 1017 model card

DeepSeek's 17 Oct 2026 MIT-licensed model card for DeepSeek-V4.1-Flash-1017, compared against GLM 5.3, GPT-5.6 Sol, and Claude Opus 5.

Primary URL: https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017 ↗ · 6 benchmarks · 23 recorded cells

How this harness compiles a score

  • DeepSeek uses the Claude Code harness for Terminal-Bench 4.0 and the Mini-SWE-V2 harness for DeepSWE v1.1.
  • ProgramBench here uses binary task scoring (29.1% for 1017, 37.0% for Opus 5) and is kept on programbench-binary so it is not confused with Meta's continuous ProgramBench row.
  • Chartography on DeepSeek's card is evaluated with tools and is kept separate from Chartography (no tools).

Scope & boundaries

  • DeepSeek's launch table compares 1017 only with pre-September 2026 models (Kimi K3, GLM-5.3, GPT-5.6 Sol, and Claude Opus 5), not with Claude 5.5, GPT-6, or Gemini 4.
  • GLM-5.3's HLE cell on DeepSeek's card is marked text-only subset (†) while the other models are full HLE without tools, so GLM-5.3 is noted accordingly.
